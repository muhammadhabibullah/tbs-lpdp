Three cooperating sub-projects form a closed content pipeline: `schema.json` defines the canonical question contract; `sample/` provides hand-authored exemplars of each subtest (verbal, kuantitatif, pemecahan_masalah); `generator/` reads the schema and samples to produce numbered JSON question files deterministically via per-topic modules (aritmetika, aljabar, deret_angka, figures, etc.); `bank/1..12/` are the published output packages, each mirroring the same three-subtest layout plus an `images/` folder for geometry SVGs. The generator's `validate_bank.py` and `push_to_supabase.py` bridge the generated files into the Supabase-backed bank used at runtime, while each package's `package.json` marks it as a standalone npm artifact consumable by the frontend.
