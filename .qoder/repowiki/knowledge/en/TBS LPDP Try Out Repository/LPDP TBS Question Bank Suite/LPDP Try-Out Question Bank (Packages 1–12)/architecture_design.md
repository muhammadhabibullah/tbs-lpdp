The bank is a flat data repository under `questions/bank/`, with one top-level directory per package (1–12). Each package mirrors an identical internal layout: a `package.json` declaring package-level metadata (`id`, `title`, `difficulty`, `ai_model`, `ai_company`, `ai_model_description`), three subtest subdirectories (`verbal`, `kuantitatif`, `pemecahan_masalah`) holding one JSON file per question, and an `images/` folder of SVG assets referenced by questions. Every question file follows a uniform schema with fields `id`, `package`, `subtest`, `number`, `type`, `question_text`, optional `image`/`passage`, an `options` array keyed A–E, a single `correct_option`, per-option `explanations`, plus `difficulty`, `source`, and `verified`. There is no runtime code — consumption is done by reading these JSON files from disk, so the module's architecture is purely declarative data with strict naming conventions as its contract.
