Install via `pip install -r requirements.txt`. Generators run as `python3 <script>.py --package N [--count N] [--blanks 1|2] [--interior|--leading] [--seed S] [--bank-dir PATH]`. Validation: `python3 validate_bank.py [--strict]`. Figure regeneration/diff: `python3 figures.py [--check|--only <id>] [--link]`. Publishing: `python3 push_to_supabase.py --package N [--publish|--dry-run]` (requires `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` env vars for live runs).
