This leaf module is purely auxiliary — it contains no application code. It is split into three independent concerns: `docs/` stores human-readable design notes (a capacity-guard deep-dive in `CAPACITY_GUARD.md` plus an evolving series of `TECHNICAL_REQUIREMENTS_V*.md` files that track spec changes); `scripts/bump_version.py` is a standalone CLI that reads/writes four version-bearing files (`web/src-tauri/tauri.conf.json`, `web/src-tauri/Cargo.toml`, `web/src-tauri/Cargo.lock`, `web/package.json`) using regex substitution; `exambrowser-ui/` is a static asset folder holding screenshot images and a one-line README describing them as UI reference material for the frontend team.
