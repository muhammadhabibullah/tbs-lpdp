Three parallel configuration trees mirror each other across IDEs — `.agents/` (generic), `.claude/` (Claude Code), and `.codex/` (Codex) — so the same question-generation workflow is available regardless of editor. Each tree contains an `agents/` directory with paired roles (`question_generator` / `question_reviewer`, plus snake_case aliases) and a shared `skills/lpdp-question-generation/SKILL.md` that defines the question-generation rules enforced by all agents. The root `.agents/AGENTS.md` is the project-wide onboarding doc: it describes build flavors (web production, dev mock, offline Tauri app), exam format, repository map, generator commands, and security constraints (answer-key secrecy, Supabase service-role key handling). `.claude/launch.json` provides a VS Code launch configuration that starts the SPA with `VITE_USE_MOCK=true` so agents can develop against the local bank without Supabase. Dependency direction is one-way: agents read SKILL.md and AGENTS.md; they do not import code.
