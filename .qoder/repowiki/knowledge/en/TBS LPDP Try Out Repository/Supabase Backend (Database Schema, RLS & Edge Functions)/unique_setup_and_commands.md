Schema must be applied in strict order via `supabase db push`: `schema.sql` → `schema_v2_reports.sql` → `schema_v3.sql` → `maintenance.sql`; anonymous sign-in must be enabled in Auth and a public storage bucket named `question-images` must exist before deployment. The edge function requires `SUPABASE_URL`, `RESEND_API_KEY`, `REPORT_DIGEST_TO`, `REPORT_DIGEST_FROM`, and either `SUPABASE_SECRET_KEYS` (JSON with `automations` and `default` keys) or `AUTOMATIONS_API_KEY`/`SUPABASE_SERVICE_ROLE_KEY`.
