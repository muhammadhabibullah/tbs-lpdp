The module is a standard Tauri v2 Rust crate (`Cargo.toml`) split into two source files: `src/main.rs` is a thin entry point that only suppresses the Windows console window in release and delegates to `tbs_lpdp_app_lib::run()`; `src/lib.rs` defines the actual Tauri `Builder`, registers the enabled plugins (`dialog`, `fs`, `opener`, `process`, and conditionally `updater` behind `#[cfg(desktop)]`), exposes one native command `print_page` (desktop-only via `window.print()`, returns `false` on mobile), and mounts the log plugin only in debug builds. The crate is compiled as `staticlib` + `cdylib` + `rlib` so both desktop binaries and mobile targets can link against it. Platform capability scoping is declared in `capabilities/default.json` (scoped filesystem access under `$APPDATA/bank`, dialog, opener for GitHub URLs and mailto links) and `capabilities/desktop.json` (updater + process restart, macOS/Windows/Linux only). `tauri.conf.json` configures the product metadata, a single centered main window, CSP, bundle targets (`app`, `dmg`, `nsis`, `appimage`, `deb`, `rpm`), updater endpoints pointing at GitHub releases with a minisign pubkey, and Android debug suffix. `build.rs` invokes `tauri_build::build()` to generate context and schemas under `gen/`. Android scaffolding lives under `gen/android/` (Gradle project, Kotlin `MainActivity`, resources, icons) generated by Tauri's mobile pipeline.
