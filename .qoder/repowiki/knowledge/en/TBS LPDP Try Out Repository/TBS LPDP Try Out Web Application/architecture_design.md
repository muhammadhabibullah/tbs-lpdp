The project is organized as a monorepo-style workspace under `web/` with three cooperating layers: (1) `src/` holds the React SPA (pages, components, contexts, hooks, and `lib/` API clients against Supabase or a local offline backend); (2) `vite/` provides custom Vite plugins (`bank-artifact`, `bank-asset-plugin`, `mock-bank-plugin`) that read the git-backed question bank, compile it into a content-addressed artifact, and serve it to both the browser dev server and the bundled app; (3) `src-tauri/` wraps the same built SPA in a Rust/Tauri shell, sharing the identical `src/` codebase so web and offline builds stay in lockstep. The `scripts/` directory bridges the layers by publishing the bank artifact and patching Android signing metadata. Configuration flows from `.env.*` files into `lib/config.ts` and `appRuntime.ts`, which both the web runtime and Tauri bundle consume identically.
