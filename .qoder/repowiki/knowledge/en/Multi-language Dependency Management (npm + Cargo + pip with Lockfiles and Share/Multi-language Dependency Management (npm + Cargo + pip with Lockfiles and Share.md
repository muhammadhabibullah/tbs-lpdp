## Overview

This monorepo manages dependencies across three distinct language ecosystems — JavaScript/TypeScript (web SPA), Rust (Tauri desktop/mobile wrapper), and Python (question-bank generator) — each using its native package manager, with lockfiles committed to version control and a shared version-bump script keeping the app manifest versions in sync.

## Systems by Language

### JavaScript / TypeScript (web)
- **Package manager**: npm. Dependencies declared in `web/package.json` under `dependencies` and `devDependencies`, pinned with caret ranges (`^2.45.4`, `^18.3.1`, etc.).
- **Lockfile**: `web/package-lock.json` (lockfileVersion 3) is committed to the repo, pinning every transitive dependency to an exact version and integrity hash from `https://registry.npmjs.org/`. No vendored `node_modules` are checked in; the directory exists locally but is gitignored.
- **Engine constraint**: `"engines": { "node": ">=22.18" }` enforces a minimum Node.js version.
- **Registry**: Standard public npm registry; no `.npmrc`, private registries, or token configuration found in the repository.
- **Key packages**: React 18, Vite 7, TypeScript 5, Supabase JS client, and the Tauri plugin suite (`@tauri-apps/api`, `plugin-dialog`, `plugin-fs`, `plugin-opener`, `plugin-process`, `plugin-updater`).

### Rust (Tauri app)
- **Package manager**: Cargo. Dependencies declared in `web/src-tauri/Cargo.toml` under `[dependencies]` and `[build-dependencies]`; versions use semver ranges (e.g. `tauri = "2"`, `serde_json = "1"`).
- **Lockfile**: `web/src-tauri/Cargo.lock` is committed and auto-generated by Cargo, recording exact resolved versions and checksums from `registry+https://github.com/rust-lang/crates.io-index`.
- **Target-specific deps**: Conditional compilation via `[target.'cfg(not(any(target_os = "android", target_os = "ios")))'.dependencies]` to exclude the updater plugin on mobile targets (documented in a comment referencing AP-6/AP-7).
- **Rust toolchain**: `rust-version = "1.77.2"` pins the MSRV in `Cargo.toml`.

### Python (questions/generator)
- **Dependency file**: `questions/generator/requirements.txt` lists two runtime dependencies with minimum-version constraints: `jsonschema>=4.21` and `requests>=2.31`.
- **No lockfile**: There is no `requirements.lock`, `Pipfile.lock`, or `poetry.lock`; only the loose `requirements.txt` is tracked.
- **Usage**: The generator scripts (`aljabar.py`, `aritmetika.py`, `figures.py`, `push_to_supabase.py`, `validate_bank.py`) import these libraries directly.

## Cross-Cutting Conventions

### Single source of truth for app version
The `scripts/bump_version.py` script is the authoritative mechanism for bumping the application version across all manifests:
- Reads the current version from `web/src-tauri/tauri.conf.json`.
- Supports semantic version increments (`patch`, `minor`, `major`) or explicit `X.Y.Z`.
- Writes the new version into four files atomically per run: `tauri.conf.json`, `Cargo.toml`, `Cargo.lock`, and `web/package.json`.
- Invoked via `npm run app:version` (`python3 ../scripts/bump_version.py`), tying it to the NPM workflow.

### Lockfiles are version-controlled
Both `package-lock.json` and `Cargo.lock` are committed, ensuring reproducible builds across environments. This is the primary determinism guarantee for the JS and Rust toolchains.

### No vendoring
There is no vendored copy of third-party code in this repository. All dependencies are fetched at build time from their respective public registries (npm registry, crates.io). The `web/node_modules/` directory appears in the tree listing but is not part of the committed source.

### No private registries or proxies
No `.npmrc`, `Cargo.config.toml`, `pip.conf`, or environment variables referencing private registries were found. All packages resolve against public indexes.

### Question bank metadata is not a dependency manifest
Each question set under `questions/bank/<N>/package.json` contains only metadata fields (`id`, `title`, `difficulty`, `ai_model`, `ai_company`, `ai_model_description`) — these are data artifacts consumed by the web app's bank reader, not npm dependency declarations.

## Key Files

- `web/package.json` — JS/TS dependencies and devDependencies, engine constraint, NPM scripts.
- `web/package-lock.json` — Deterministic npm resolution snapshot.
- `web/src-tauri/Cargo.toml` — Rust crate manifest with version-pinned MSRV and conditional target dependencies.
- `web/src-tauri/Cargo.lock` — Deterministic Cargo resolution snapshot.
- `questions/generator/requirements.txt` — Python runtime dependencies.
- `scripts/bump_version.py` — Shared version-bump utility that synchronizes version strings across Tauri config, Cargo manifest, Cargo lock, and package.json.
