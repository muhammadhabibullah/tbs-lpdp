Three build flavors share one codebase: default web production (`npm run build`), dev mock (`VITE_USE_MOCK=true npm run dev`), and offline app (`vite --mode app` / `npm run app:dev`). The question bank is validated and published via `python3 questions/generator/validate_bank.py` and `push_to_supabase.py`, then compiled into a digest-pinned artifact with `npm run build:bank`. Signing material (minisign private key, Android keystore) lives only in GitHub Actions secrets and is never committed.
