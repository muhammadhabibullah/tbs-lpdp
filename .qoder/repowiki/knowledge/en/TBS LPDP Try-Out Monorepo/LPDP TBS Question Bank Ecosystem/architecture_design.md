Three cooperating sub-projects form a closed content pipeline anchored on `schema.json`, which defines the canonical question contract enforced by both hand-authored samples in `sample/` and every generated file. The `generator/` toolchain reads this schema plus per-topic modules (aritmetika, aljabar, deret_angka, figures, peluang_kombinatorik, etc.) to deterministically produce numbered JSON questions into each `bank/<n>/` package under the fixed three-subtest layout (`verbal`, `kuantitatif`, `pemecahan_masalah`) alongside an `images/` folder of geometry SVGs. Each package is self-contained via its own `package.json`, making it an npm artifact for frontend consumption, while `validate_bank.py` checks all generated files against `schema.json` and `push_to_supabase.py` publishes them to the Supabase-backed runtime store. The generator's deterministic seeding guarantees that repeated runs reproduce identical question sets across all 12 packages.
