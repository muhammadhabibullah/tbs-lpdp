`node scripts/build-bank.ts [--out <dir>] [--bank-dir <dir>] [--skip-validate]` emits `manifest.json` + `bank-<digest>.json`; requires full git history (`fetch-depth: 0`) or exits with an error. `node scripts/patch-android-signing.ts` must be run after `tauri android init` and before Gradle build to inject release signing configuration from `src-tauri/gen/android/keystore.properties`.
