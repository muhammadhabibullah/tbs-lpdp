Three layers share one `src/` codebase so web and offline builds stay identical: (1) `src/` is a React/Vite SPA whose UI code calls abstracted clients in `lib/api.ts` / `lib/localApi.ts` to talk either to Supabase or an embedded offline engine; (2) `vite/` compiles the git-backed question bank into a content-addressed artifact and serves it through custom Vite plugins (`bank-artifact`, `bank-asset-plugin`, `mock-bank-plugin`) consumed by both the dev server and the production bundle; (3) `src-tauri/` is a Rust/Tauri shell that bundles the built SPA plus the embedded bank, reusing the exact same `src/` sources and configuration. Cross-layer wiring happens at build time — the bank compilation step must precede any `npm run build` or `tauri dev` invocation — and at runtime via `lib/config.ts` / `lib/appRuntime.ts`, which read `.env.*` variables once and are consumed identically by the browser and the Tauri process.
